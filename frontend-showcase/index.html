Help & Documentation

What is This?

This is an Intelligent Microgrid Energy Management System (EMS) that demonstrates how advanced control algorithms optimize power distribution in renewable energy systems.

How It Works

The system compares two optimization algorithms:

  • Rule-Based Control: Uses IF-THEN logic based on battery state and power deficit
  • Fuzzy Logic Control: Uses soft membership functions for smoother decisions

Getting Started

  1. Select a Case: Choose from 6 preset cases (Residential, Industrial, etc.) or use Synthetic Scenario for custom parameters
  2. Configure Time Period: Select Morning/Afternoon/Evening/Night to adjust solar generation levels
  3. Run Simulation: Click the "Run Simulation" button to execute the control algorithms
  4. View Results: Check Metrics for key performance indicators and Charts for detailed analysis
  5. Animate: Click Play to watch the simulation unfold second-by-second

Understanding the Dashboard

Cost Optimization: Shows baseline cost vs optimization savings and efficiency percentage
Metrics: Real-time solar output, battery charge level, load demand, and grid power
Charts: Visualizes energy flow, algorithm performance, and battery behavior over time
Logs: System messages and algorithm decisions as they happen

Preset Cases Explained

  • Residential: Typical home energy consumption pattern
  • Industrial: High-power industrial facility with consistent demand
  • High Solar: Abundant solar capacity scenario
  • Low Solar: Limited solar generation scenario
  • Small Battery: Microgrid with limited storage capacity
  • Large Battery: Microgrid with high battery capacity

Manual Controls (Synthetic Scenario)

When you select "Synthetic Scenario", you can manually adjust:

  • Load 1, 2, 3: Three independent power consumption sources (0-500 kW each)
  • Solar Scale: Solar generation level (0-1 scale, or use time period buttons)
  • Battery Capacity: Available battery storage size (50-1000 Wh)

Electrical Perspective

Mathematical Foundation: The system is built on fundamental electrical engineering principles and energy optimization equations.

Key Equations:

• Power Balance: P_load = P_solar + P_battery + P_grid

• Energy: E = P × Δt (Watt-hours)

• Battery SOC: SOC(t) = SOC(t-1) + (P_batt × Δt) / (Battery_Capacity × 3600)

• Cost: Cost = Σ(P_grid × Tariff × Δt / 3600)

• Grid Power: P_grid = max(0, P_load - P_solar - P_batt_discharge)

• Battery Dispatch (Fuzzy): P_batt_ref = f(Deficit_Membership, SOC_Membership) via defuzzification

Control Objectives:

  • Minimize grid power purchase during peak tariff hours
  • Maintain battery SOC within safe limits (20-90%)
  • Maximize renewable energy utilization
  • Ensure all loads are served with priority allocation

System Parameters: Battery capacity ranges (50-1000 Wh), Solar generation (0-100%), Load consumption (0-500 kW per phase), Peak tariff: ₹8/kWh, Off-peak: ₹5/kWh

  • Compare scenarios: high battery vs low battery to understand storage importance
